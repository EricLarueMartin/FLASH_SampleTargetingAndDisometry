Live firing route

In Live mode each pulse is one put of {{ fire_pv }}, sent through an SSH session to a control-room account the IOC already lets write. The session stays open for the whole run, so a pulse costs a few ms. Pulses follow a fixed clock (pulse k at t0 + k×delay), so send times never add up into the total. Without a host set here, Live mode is unavailable (this Pi has read-only CA access).
