Rotates the web preview and exported preview images. Saved RAW dosimetry files keep the original sensor values.

Choose whether dragging on the preview selects a zoom region or uses the browser's normal image drag behavior.

Timing

ESP delay from the accepted input trigger edge to the camera shutter pulse. This is the laser-charge-to-scintillation timing offset.

Shutter pulse width used when Capture mode is Targeting. Use a wider gate when aligning and focusing. Minimum enforced value is 30 us.

Shutter pulse width used when Capture mode is Dosimetry. This should be tight enough to capture the scintillation signal with low background. Minimum enforced value is 30 us.

Dose calibration

Background-subtracted fitted peak in DN that corresponds to 1 Gy, applied per pixel to beam-fit results (amplitude, offset, noise). Fit integrals become Gy·px². The default comes from the 2026-10-13 film cross-calibration; a saved value overrides it on this Pi for every browser.

Fit results always show the 1σ statistical fit error. When checked, Gy values also include the calibration uncertainty, added in quadrature.

Choose the primary unit for beam-fit results; the other unit is shown in parentheses.

Wi-Fi

Host a network for phone focusing, or join another Wi-Fi network. Only one mode can run at a time. Changing Wi-Fi may disconnect your phone; reconnect using the new settings.

Your phone receives an address automatically. Open the hotspot IP in its browser. The Pi hostname stays pi-06-ioc.

For personal networks with a shared password (WPA/WPA2). The network assigns the Pi's IP automatically; Ethernet remains preferred. Enterprise login and captive portals are not supported here.

ESP Trigger Logic

When enabled, the ESP sends the delayed shutter pulse to the camera after a trigger. When disabled, trigger inputs are ignored for camera output. Capture and Arm turn this back on for normal operation.

Sets which ESP input edge starts the delay. Active high means a rising edge triggers; active low means a falling edge triggers.
